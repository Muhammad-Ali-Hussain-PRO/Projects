# SpecServe

**Status: In progress.**

The exact speculative-sampling rejection and correction rule on toy distributions, with context-dependent distribution checks.

## Implemented

- Autoregressive draft proposals with target acceptance ratios
- Positive target-minus-draft correction distribution
- Bonus target token after an accepted draft block
- Analytic mass identity and seeded context-dependent sampling tests

## Reference behavior

A draft proposal `x` is accepted with probability `min(1, p(x)/q(x))`. On the first rejection, the replacement is drawn from the normalized positive part of `p-q`; later proposals are discarded. If every proposal is accepted, a bonus token is sampled from the target after the accepted prefix. Draft and target distributions must share a vocabulary and already reflect the intended sampling policy.

The test suite covers identical distributions, disjoint support, normalization errors, invalid vocabulary shapes and the analytic one-token mass identity. It also samples 200,000 two-token sequences from a context-dependent three-token toy model, using seed 20261005. The maximum absolute joint-probability error is recorded in `verification.json`; the acceptance threshold for that check is 0.004.

The sampling rule preserves the target law in exact arithmetic. This implementation uses floating-point probabilities and finite-sample tests. A model-server speedup cannot be inferred from these tests.

## Not yet implemented

- Integrate real draft and target model adapters
- Batch target verification and handle KV-cache rollback
- Measure end-to-end latency and distribution fidelity on real models

Toy probability callbacks and sequential target evaluation; no real model serving, batching, streaming or measured speedup.

## Build and verify

Run from this directory with a C++17 compiler and Make:

```sh
make test
cat verification.json
```

The tests currently pass 18 checks. The report is generated by the executable, and a failed check makes the command fail. The shared helper is `../test_support.hpp`; keep the research directory structure when copying the project. Build flags include `-Wall -Wextra -Werror`.

## Primary sources

- [Fast Inference from Transformers via Speculative Decoding, Leviathan, Kalman and Matias, ICML 2023](https://proceedings.mlr.press/v202/leviathan23a.html): Section 2.3, Algorithm 1 and Appendix A.1. The project implements its sampling rule, not the paper's serving benchmark.
