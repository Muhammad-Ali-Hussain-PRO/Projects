# GroupAlign GRPO

**Status: In progress.**

Group-relative reward normalization and a clipped policy objective, verified on hand-calculated fixtures.

## Implemented

- Group-relative advantages with a zero-variance safeguard
- Sign-correct clipped importance-ratio surrogate
- Sampled reference-policy KL penalty
- Equal completion weighting with token means and numerical tests

## Reference behavior

The implementation evaluates the outcome-supervision form: `(reward - group_mean) / population_std`, reused across each completion's tokens. If the standard deviation is at most the configured numerical epsilon, advantages are explicitly zero.

For each token it takes `min(ratio * advantage, clamp(ratio, 1-epsilon, 1+epsilon) * advantage)`. The reference penalty uses `expm1(reference_logp - policy_logp) - (reference_logp - policy_logp)`. This is a sampled estimator, not an exact vocabulary-wide KL divergence. Tokens are averaged within a completion, then completions are averaged equally.

Tests exercise both advantage signs on both clipping boundaries, population normalization, positive affine invariance, constant rewards, a hand-computed KL value, unequal completion lengths and malformed inputs. The code evaluates scalars and does not compute gradients.

## Build and verify

Run from this directory with a C++17 compiler and Make:

```sh
make test
cat verification.json
```

The tests currently pass 19 checks. The report is generated by the executable, and a failed check makes the command fail. The shared helper is `../test_support.hpp`; keep the research directory structure when copying the project. Build flags include `-Wall -Wextra -Werror`.

## Primary sources

- [DeepSeekMath, Shao et al., Section 4.1](https://arxiv.org/abs/2402.03300): GRPO objective, reward normalization and sampled KL estimator. Population standard deviation and the zero-variance safeguard are explicit choices in this reference fixture.
