# Transformer Forge

**Status: In progress.**

A tiny forward block with tested rotary positions, SwiGLU and grouped-query attention.

## Implemented

- Adjacent-pair RoPE with correct dimension-dependent frequencies
- Causal grouped-query attention with shared KV heads
- Pre-norm residual block and SwiGLU feedforward
- Numerical identity, grouping and causal-prefix tests

## Reference behavior

The fixture uses model dimension 8, four query heads, two KV heads and head dimension 2. Projections are explicit matrices; RMSNorm scales are fixed to one. RoPE rotates adjacent coordinate pairs with angle `position * 10000^(-2j / d)`. Query head `h` uses KV head `h / (query_heads / kv_heads)`.

Tests check position-zero identity, known rotation values, norm preservation, relative-position dot products, hand-calculated SwiGLU values, uniform-score attention, head grouping, malformed shapes and invariance of a prefix when future tokens are added. Dense loops favor inspectability, not performance. The adjacent-pair convention must be converted explicitly for checkpoints using a split-half convention.

## Not yet implemented

- Add checkpoint loading, tokenization and a full model stack
- Implement backward passes and a training experiment

Toy dimensions and deterministic synthetic weights; CPU forward only. No trained model, KV cache, GPU kernels or full training runtime.

## Build and verify

Run from this directory with a C++17 compiler and Make:

```sh
make test
cat verification.json
```

The tests currently pass 16 checks. The report is generated by the executable, and a failed check makes the command fail. The shared helper is `../test_support.hpp`; keep the research directory structure when copying the project. Build flags include `-Wall -Wextra -Werror`.

## Primary sources

- [RoFormer, Su et al.](https://arxiv.org/abs/2104.09864): original rotary-position construction and relative-position identity.
- [Llama 2, Touvron et al.](https://arxiv.org/abs/2307.09288): architectural use of RMSNorm, SwiGLU, RoPE and grouped-query attention. This fixture is not a Llama checkpoint implementation.
