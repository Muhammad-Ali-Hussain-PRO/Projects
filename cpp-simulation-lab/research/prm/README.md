# ProcessLens PRM

**Status: In progress.**

A deterministic arithmetic step validator that establishes the data and feedback boundary for future process supervision.

## Implemented

- Exact bounded rational-expression parser
- Step verdicts with expected values and feedback
- Commit-only-on-success dependency tracking
- Tests for incorrect steps, invalid syntax and arithmetic bounds

## Reference behavior

A step consists of a new symbol, an arithmetic expression and a claimed exact value. Expressions support integer literals, previously verified symbols, parentheses, unary signs and `+ - * /`. Only correct steps enter the environment; a wrong intermediate step cannot silently become a dependency of later steps.

Example: `a := 3 * (4 + 2)` with claimed value `18` is accepted. `b := a / 4` with claimed value `9/2` is then accepted. Claiming `21` for `a + 2` returns expected value `20` and leaves the environment unchanged.

Numerators and denominators are normalized and capped at 1e9 after reduction; intermediate cross-products stay within signed 64-bit arithmetic. Inputs longer than 4096 characters are rejected. Tests cover precedence, fractions, dependency validity, wrong values, divide-by-zero, unsupported syntax, symbol replacement and bounds.

## Not yet implemented

- Define labeled reasoning-trajectory schema and dataset loader
- Train and calibrate a learned step-scoring model
- Evaluate general reasoning and held-out trajectory selection

Deterministic validator only; not a trained process reward model. Supports structured arithmetic expressions, not natural-language reasoning or general proofs.

## Build and verify

Run from this directory with a C++17 compiler and Make:

```sh
make test
cat verification.json
```

The tests currently pass 14 checks. The report is generated by the executable, and a failed check makes the command fail. The shared helper is `../test_support.hpp`; keep the research directory structure when copying the project. Build flags include `-Wall -Wextra -Werror`.

## Primary sources

- [Let's Verify Step by Step, Lightman et al.](https://arxiv.org/abs/2305.20050): process-supervision research motivating step-level feedback.
- [OpenAI PRM800K source repository](https://github.com/openai/prm800k): the published step-feedback dataset and schema to study before designing a learned-model experiment.

No claim is made about the training or internal architecture of any current proprietary reasoning model.
